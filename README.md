# EVOGEN 14.0 — Tech युग

Official website for **EVOGEN 14.0**, the annual tech fest organized by the BCA Department of Karnatak Law Society's **Gogte College of Commerce**. This edition's theme is **Tech Yuga** — where tradition meets technology.

> *"E V O L V I N G  G E N E R A T I O N S."*

## 🌐 Live Preview

Open `index.html` in your browser or [deploy via GitHub Pages](https://pages.github.com/).

## ✨ Features

- **Immersive Hero Section** — Fullscreen background video with animated CTA buttons
- **Story Slideshow** — Image carousel showcasing highlights from Evogen 13.0
- **What's New Slider** — Feature cards with smooth horizontal scrolling
- **About & Past Events** — Parallax backgrounds with event history and context
- **Team Section** — Grid layout with hover effects and social links for organizers
- **Fully Responsive** — Mobile-first design with hamburger nav and adaptive layouts
- **Indian Cultural Design** — Sanskrit typography (Cinzel + Cormorant Garamond), gold & saffron palette, Devanagari script integration

## 🛠️ Tech Stack

- **HTML5** — Semantic, single-page structure
- **CSS3** — Custom properties, CSS Grid, Flexbox, media queries, parallax scrolling
- **JavaScript** — Vanilla JS for slideshow, feature slider, scroll-based header, and mobile navigation
- **Font Awesome 6** — Icons for navigation, social links, and feature cards
- **Google Fonts** — Cinzel (headings) + Cormorant Garamond (body)

## 📁 Project Structure

```
Evogen/
├── index.html          # Single-page website (HTML + CSS + JS)
└── README.md
```

> **Note:** Image and video assets (team photos, slideshow images, background video) are referenced in the HTML but not included in the repo. Add your own media files to the root directory to match the `src` paths used in the code.

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/vrd07/Evogen.git

# Open in browser
cd Evogen
open index.html    # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```

No build tools or dependencies required — it's a single static HTML file.
